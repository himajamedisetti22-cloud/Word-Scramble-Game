## Description
A simple Python game where players unscramble shuffled words. The program randomly selects a word, shuffles its letters, and asks the user to guess the original word.

## Features
- Random word selection
- Word scrambling
- User input validation
- Score tracking (optional)

## Technologies Used
- Python 3
- random module

## How to Run
1. Download the project files.
2. Open a terminal in the project folder.
3. Run:
   python word_scramble.py

## Example
Scrambled Word: tynpho
Guess: python
